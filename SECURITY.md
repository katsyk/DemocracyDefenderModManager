# Security Policy

## Supported versions

Only the latest release of Democracy Defender Mod Manager (DDMM) is supported. Please update before reporting an
issue you haven't confirmed still reproduces on the latest release.

## Reporting a vulnerability

Please report security vulnerabilities privately, not through a public GitHub issue.

Private vulnerability reporting is enabled for this repository:
<https://github.com/katsyk/DemocracyDefenderModManager/security/advisories/new>

Use that form to open a private security advisory. We'll respond, work with you on a fix, and coordinate
disclosure before anything is made public.

For anything that isn't a vulnerability report (a bug, a feature request, a question), please use the normal
issue tracker instead: <https://github.com/katsyk/DemocracyDefenderModManager/issues>
