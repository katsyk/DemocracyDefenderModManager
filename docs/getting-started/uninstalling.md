# Uninstalling

DDMM doesn't run an installer, so it doesn't need an uninstaller either.

1. If you have mods deployed, click **Purge** in DDMM first to remove them from your Helldivers 2 `data` folder
   cleanly. (See [Deploy & purge](../using/deploy-purge.md) for exactly what this deletes.)
2. Close DDMM and delete the folder you put it in — the executable, `mods/`, `settings.json`, `profiles.json`,
   and its log files all live there, so deleting the folder removes everything DDMM created.

Your Helldivers 2 installation itself is never touched beyond the `data` folder changes Deploy/Purge make.
