# Updating DDMM

DDMM is portable, so updating it doesn't touch your mods, settings, or profiles — those live in `settings.json`,
`profiles.json`, and the `mods/` folder next to the executable, and none of them are part of the download.

1. Download the new `ddmm.exe` / `ddmm` from the
   [releases page](https://github.com/katsyk/DemocracyDefenderModManager/releases).
2. Replace the old executable in your DDMM folder with the new one (keep `settings.json`, `profiles.json`, and
   `mods/` where they are).
3. Run the new version as usual.

There is no in-app auto-updater; check the releases page for new versions.

!!! tip
    If you keep the new executable in the same folder as the old install, DDMM picks up your existing mods,
    settings, and profiles automatically — there's nothing else to migrate.
